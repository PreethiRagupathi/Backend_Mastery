## SQL Basics and Data Manipulation

## 28 July 2026

## Objective

The objective of today's learning was to understand the fundamentals of SQL (Structured Query Language) by practicing basic data manipulation operations. The session focused on retrieving, filtering, inserting, updating, and deleting data using SQL queries in PostgreSQL.

---

# Topics Covered

## Introduction to SQL

Learned that SQL (Structured Query Language) is the standard language used to communicate with relational databases. It is used to create, retrieve, modify, and manage data stored in database tables.

---

## SELECT Statement

Learned how to retrieve data from a table using the `SELECT` statement.

Covered:
- Retrieving all records from a table.
- Retrieving data from specific columns.
- Understanding the purpose of data retrieval operations.

---

## WHERE Clause

Learned how to filter records based on specified conditions using the `WHERE` clause.

Practiced:
- Retrieving records that satisfy a particular condition.
- Understanding comparison operators for filtering data.

---

## INSERT Statement

Practiced inserting data into an existing table.

Learned:
- Inserting individual records.
- Inserting multiple records in a single statement.
- Maintaining correct data types and column order while inserting values.

---

## UPDATE Statement

Learned how to modify existing records stored in a table.

Practiced:
- Updating a single column.
- Updating multiple columns simultaneously.
- Using the `WHERE` clause to ensure only the intended records are modified.

---

## DELETE Statement

Learned how to remove data from a table.

Practiced:
- Deleting a specific record using a condition.
- Deleting all records from a table while retaining the table structure.
- Understood the importance of using the `WHERE` clause to avoid accidental deletion of all records.

---

# Practical Activities Completed

- Inserted multiple records into the table.

- Updated existing records using the `UPDATE` statement.
